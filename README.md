# Online Shopping Backend API

Backend API project built with Python and FastAPI, focused on
schema-driven data flow and controlled input validation.

The application uses:
- SQL database with defined schemas and constraints
- Pydantic models for request/response validation
- Clear separation between data access, validation, and API logic

Main goal of the project was to practice building a functional backend
that enforces data correctness and understands its input limits.

Work in progress.
